Fixed-point arrays

Signed fixed-point arrays.

Each value has format (n, r): n is the two’s-complement width and r is the number of fractional bits.

class fp_array.FixedPointArray(values: Any, n: int = 16, r: int = 8)

An array of signed fixed-point values in format (n, r).

Integer m is the real value m / 2**r. Real inputs are floored toward negative infinity, then saturated to the signed n-bit range. Addition and multiplication keep every result bit. re_quantize() drops fractional bits toward zero and saturates. A right shift is arithmetic and does not change (n, r).

Quantize real values into signed format (n, r).

Parameters:

  • values (array-like of float) – Real numbers. A scalar becomes a length-1 array.

  • n (int, optional) – Signed width, including the sign bit. Default is 16.

  • r (int, optional) – Fractional bit count. Default is 8.

Raises:

ValueError – If n is less than 1 or r is negative.

classmethod from_mantissas(mantissas: Any, n: int, r: int) → FixedPointArray

Build an array from integers that are already quantized.

mantissas are numerators, not real values. Integer m represents m / 2**r. Integers outside the signed n-bit range saturate. Use this when an earlier stage already produced fixed-point integers, instead of quantizing those integers as reals.

Parameters:

  • mantissas (int or array-like of int) – Integer numerators in format (n, r).

  • n (int) – Signed width, including the sign bit. Must be at least 1.

  • r (int) – Fractional bit count. Must be at least 0.

Returns:

Array of those integers in format (n, r). A scalar becomes a length-1 array.

Return type:

FixedPointArray

Raises:

  • TypeError – If mantissas is not an integer or an integer array.

  • ValueError – If n or r is not a valid format.

re_quantize(n: int, r: int) → FixedPointArray

Change this array’s format in place and return it.

Dropped fractional bits are truncated toward zero. Growing the fraction shifts mantissas left. Integers that do not fit in the new width saturate. The operand arrays passed to earlier operations are not affected because this updates only this array.

Parameters:

  • n (int) – Signed width of the new format.

  • r (int) – Fractional bit count of the new format.

Returns:

This array, now in format (n, r).

Return type:

FixedPointArray

Raises:

ValueError – If n or r is not a valid format.

Sine-generator DAC

Return the DACP and DACN values and voltages for each clock.

Call it with a register dictionary, for example generate_dac_values(4096, **registers).

Parameters:

  • n_samples (int) – Number of clocks.

  • frequency (int, optional) – Phase step added each clock, from 0 to 65535. Default is 0.

  • amplitude_scale (int, optional) – Scale from 0 to 15. The cosine is about scale/15 of full scale. Default is 8.

  • amplitude (int, optional) – The cosine is shifted right by 15 minus this value. Default is 15.

  • dsm_enable (bool, optional) – True runs the delta-sigma modulator. False truncates by 8 bits. Default is False.

  • dacp_mode (str, optional) – "AC" uses the cosine. "DC" holds dacp_dc_value. Default is "DC".

  • dacn_mode (str, optional) – "AC" uses the negated cosine. "DC" holds dacn_dc_value. Default is "DC".

  • dacp_dc_value (int, optional) – DACP code from 0 to 255 in DC mode. Default is 0.

  • dacn_dc_value (int, optional) – DACN code from 0 to 255 in DC mode. Default is 0.

  • vdd (float, optional) – Supply in volts. Voltage is this value times the code divided by 256. Default is 3.3.

Returns:

Columns phase, cosine, dacp_value, dacn_value, dacp_voltage, dacn_voltage, and error.

Return type:

pandas.DataFrame

Raises:

  • TypeError – If an argument has the wrong type.

  • ValueError – If a count, scale, mode, or code is out of range.

nssar.convert_nssar(vin_p: ndarray, vin_n: ndarray, do_dwa: bool = True, incremental_mode: bool = True, reset_dwa: bool = False, n_quantizer_bits: int = 3, cap_mismatch_sigma: float = 0.0, vrefp: float = 1.0, vrefn: float = 0.0, osr: int = 32) → DataFrame

Return one row per sample clock for the noise-shaping SAR.

Call it with a register dictionary, for example convert_nssar(vin_p, vin_n, **registers).

Parameters:

  • vin_p (numpy.ndarray) – Positive input voltage, one value per sample clock.

  • vin_n (numpy.ndarray) – Negative input voltage, one value per sample clock. Same length as vin_p.

  • do_dwa (bool, optional) – True rotates the capacitors from the data-weighted averaging pointer. Default is True.

  • incremental_mode (bool, optional) – True resets the integrators and counters every osr clocks. Default is True.

  • reset_dwa (bool, optional) – True clears the averaging pointer when the integrators reset. Default is False.

  • n_quantizer_bits (int, optional) – Number of SAR decisions, from 1 to 16. Default is 3.

  • cap_mismatch_sigma (float, optional) – Standard deviation of each capacitor value about 1. Default is 0.

  • vrefp (float, optional) – Positive reference voltage. Default is 1.

  • vrefn (float, optional) – Negative reference voltage. Default is 0.

  • osr (int, optional) – Clocks per output sample. Default is 32.

Returns:

One row per sample clock. Columns are input, sample_input, integrator_input, vin_p, vin_n, vint_p, vint_n, quantizer_decision, dac_feedback, error, integrator_1, integrator_2, incremental_1, incremental_2, reset, sample_output, and dwa_pointer. incremental_1 and incremental_2 are signed integer counts, format (n, 0), with n wide enough to hold the count.

Return type:

pandas.DataFrame

Raises:

  • TypeError – If an argument has the wrong type.

  • ValueError – If a length, count, reference, or deviation is out of range.
